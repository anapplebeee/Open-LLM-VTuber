This directory contains the background images for Open-LLM-VTuber.
You can put more images into this directory. You can switch between them in the frontend UI.

- `cozy-live-room.png`：暖色书房直播间背景，书柜/两侧书桌环绕，适合作为默认直播背景。
- `cozy-live-room.svg`：同背景的可编辑矢量源文件。

- `cozy-cute-bgm.wav`：原创免版权可爱轻音乐循环，默认直播间 BGM。

- 将已授权的《解脱》音频放到 `backgrounds/jietuo-pulizi.wav` 或 `.mp3`，live-view 会优先作为默认 BGM；文件不存在时自动回退到 `cozy-cute-bgm.wav`。
