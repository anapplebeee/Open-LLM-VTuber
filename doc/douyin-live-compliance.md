## 核心规则摘要

### 内容安全

- 禁止色情低俗、擦边、性暗示、身体敏感部位展示或评价。
- 禁止暴力血腥、自伤自残、赌博诈骗、毒品枪支、违法交易、危险行为。
- 禁止仇恨、歧视、侮辱、威胁、人肉搜索、网络暴力、造谣和侵犯隐私。
- 不主动制造政治、宗教、民族、地域、性别对立。
- 不虚假宣传、不冒充他人、不承诺无法验证的收益或结果。

### 未成年人保护

- 未满 16 周岁不得出镜直播。
- 年满 16 未满 18 周岁开播必须取得监护人书面同意。
- 禁止诱导未成年人打赏、消费、私下联系。
- 禁止利用未成年人牟利，禁止模拟未成年人语气或使用童装、校服等未成年人特征。
- 发现观众自称未成年人时，停止打赏/暧昧话题，建议在监护人陪同下观看。

### 打赏与互动

- 禁止营造虚假亲密关系、情感欺诈、诱导打赏。
- 禁止以礼物、打赏、榜单排名作为回答问题、唱歌、加联系方式的条件。
- 禁止组织消费接龙、消费排名、炫耀或攀比打赏金额。
- 感谢礼物时不报具体金额、不报榜单排名、不引导继续消费。

### 导流与商业

- 不引导站外私下交易、扫码加微信/QQ/群。
- 不发布未经授权的广告、联系方式或第三方导流信息。
- 电商直播另需遵守商品资质、宣传和售后规则。

### 版权

- 不主动要求播放未经授权的歌曲、影视、游戏或他人作品。
- 点歌功能涉及的音乐版权由主播/运营确认；直播中不承诺任意点播。
- 如平台提示音乐版权风险，应关闭音乐或替换为已授权素材。

### AI 主播

- 被问身份时明确是 AI 主播“小鲸”，不冒充真人。
- 不声称拥有现实身体、线下经历或未执行的动作。
- 平台若要求 AI 生成内容标识，运营侧需在直播间/画面中完成标识。

## 已接入的代码约束

`src/open_llm_vtuber/live/douyin_policy.py` 的 `DOUYIN_LIVE_POLICY` 会追加到
`LiveStreamerAgent` 的系统提示，普通聊天和直播回复共用。

约束不是只在 prompt 里“建议”，而是和现有输出过滤、身份约束、编程边界一起组成
多层约束：

```text
系统提示（人格 + 抖音规范 + 编程边界 + 热梗规则）
  -> 模型回复
  -> sanitize_live_reply
  -> programming_guard
  -> 前端/字幕显示与 TTS
```

## 开播前人工检查清单

- [ ] 画面/直播间明确标注 AI 主播身份
- [ ] 确认音乐、点歌、背景素材有授权
- [ ] 关闭或改造诱导打赏、榜单、消费接龙话术
- [ ] 未成年人保护提示和退款/举报入口可查
- [ ] 不展示二维码、微信号、站外联系方式
- [ ] 运营人员在直播中可随时中断/切歌/停播
- [ ] 开播前以抖音官方规则页的最新版本复核
