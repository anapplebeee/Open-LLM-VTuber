## 1. 项目概述

我们正在制作一位面向 B站/抖音的 AI VTuber「小鲸」。她由 Open-LLM-VTuber 驱动，通过弹幕、语音和直播事件实时生成台词，再由 TTS 播放并驱动 Live2D 角色。

现阶段使用 OLV 自带的 mao_pro 示例模型验证直播链路。本需求的目标是制作一套原创、可商用、适合实时直播的蓝鲸娘 Live2D 模型，替换示例模型。

- 角色必须支持眨眼、呼吸、说话口型、情绪表情和待机动作。
- 角色用于 16:9 横屏直播，半身构图，需在 1280×720 和 1920×1080 下清晰。
- 最终运行在 OLV 官方 Web 前端，由直播姬或 OBS 捕获窗口。
- 本需求只覆盖角色设计与 Live2D 制作；LLM、TTS、弹幕采集由我方负责。

## 5. 分层原画要求

请按 Live2D 绑定需要拆分图层，不要把整张脸、整只眼睛或整张嘴合并。所有图层需保留足够重叠区域，方便转头、眨眼和张嘴时补边。

| 组 | 必须拆分的图层 |
| --- | --- |
| 头部 | 后发、头部底色、耳朵、脸部、腮红、鼻子、左右眼白、左右虹膜、瞳孔、高光、上下眼睑、睫毛、左右眉毛、口腔、舌头、牙齿、前发、刘海阴影、呆毛 |
| 身体 | 脖子、躯干、内搭、外套/连帽、左右上臂、左右前臂、左右手（可选）、袖口、腰部、衣摆 |
| 配饰 | 鲸尾发饰、耳饰、气泡、鲸歌波纹、胸前小装饰 |
| 特效 | 可选：半透明气泡、光点、尾巴摆动辅助层 |

- 眼睛至少提供「睁开 / 半闭 / 闭合」三种状态，左右眼分开。
- 嘴至少提供「闭合 / 半开 / 张大 / 微笑 / 撇嘴」五种状态。
- 头发、衣服、配饰的重叠边缘建议外扩 20–50px，避免变形露底。
- 图层命名建议：01_head_face、02_eye_L_white、03_mouth_open 等，禁止无意义编号。
- 所有可见素材必须来自原创绘制或已获授权的素材；AI 辅助需在交付时说明。

## 6. Live2D 参数与绑定要求

| 参数 ID | 用途 | 建议范围 |
| --- | --- | --- |
| ParamAngleX / Y / Z | 头部左右、上下、倾斜 | −30～30 |
| ParamEyeLOpen / ParamEyeROpen | 左右眼开合 | 0～1 |
| ParamEyeBallX / ParamEyeBallY | 眼球视线 | −1～1 |
| ParamMouthOpenY | 说话张口；口型同步主参数 | 0～1 |
| ParamMouthForm | 嘴角表情（微笑/撇嘴） | −1～1 |
| ParamBrowLY / ParamBrowRY | 左右眉毛 | −1～1 |
| ParamBodyAngleX / Y / Z | 身体左右、前后、倾斜 | −10～10 |
| ParamBreath | 呼吸起伏 | 0～1 |
| ParamArmLA / ParamArmRA | 左右手臂 | 0～1 |
| ParamWhaleTail | 鲸尾发饰摆动（自定义） | −1～1 |
| ParamBubble | 气泡出现/漂浮（自定义，可选） | 0～1 |
| ParamCheekPuff | 鼓腮/傲娇（自定义，可选） | 0～1 |

- 必须配置 EyeBlink 参数组，包含 ParamEyeLOpen 和 ParamEyeROpen。
- 必须配置 MouthOpenY 口型组，供 OLV 播放语音时驱动。
- 头发、鲸尾、衣摆建议添加物理演算；参数幅度不要导致穿模和抖动。
- 待机动作需要可循环，循环首尾不能有明显跳变。

## 7. 表情与动作

OLV 会从 LLM 回复中提取情绪标签，再映射到模型表情。请按下表提供表情文件，表情名称可用英文小写；最终索引由我方在 model_dict.json 中配置。

| 表情名 | 用途 | 建议表现 |
| --- | --- | --- |
| neutral | 默认/平静 | 自然微笑或平静表情 |
| joy | 开心/被夸 | 眼睛弯起、嘴角上扬、轻微腮红 |
| shy | 害羞/嘴硬心软 | 移开视线、脸红、嘴角压住 |
| pout | 鼓腮/傲娇 | 鼓腮、皱眉、轻微侧头 |
| anger | 生气/警告 | 皱眉、眼神锐利，但不狰狞 |
| sad | 低落/委屈 | 眉尾下垂、眼神变软 |
| surprise | 惊讶 | 眼睛睁大、嘴巴微张 |
| smug | 得意/小骄傲 | 半眯眼、轻笑、抬下巴 |
| sleepy | 困倦/待机 | 眼皮下垂、轻微点头 |

动作组建议：

| 动作组 | 动作 | 要求 |
| --- | --- | --- |
| Idle | 待机呼吸/轻微摇摆 | 8–12 秒循环，首尾自然衔接 |
| Greet | 挥手打招呼 | 可循环 1 次，幅度适中 |
| Happy | 开心弹跳/摆尾 | 与 joy 表情搭配 |
| Pout | 鼓腮转头 | 与 pout 表情搭配 |
| Shy | 低头/移开视线 | 与 shy 表情搭配 |
| Surprise | 后仰/睁大眼 | 短动作，快速回到 idle |
| Think | 托腮/看向一侧 | 用于思考或停顿 |
