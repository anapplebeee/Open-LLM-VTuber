# 2026 热梗理解库

这份文档记录回复层使用的中文互联网热梗研究快照。代码里的
`src/open_llm_vtuber/live/memes.py` 是唯一运行时来源；这里只保存来源、
筛选原则和人工理解，不把网页正文直接注入 prompt。

## 筛选原则

- 优先选择 2026 年仍在传播、语境清楚、适合直播互动的梗。
- 只保留低攻击性、低敏感度、观众容易接住的表达。
- 不收录地域攻击、性别对立、政治隐喻、疾病/死亡、外貌羞辱、成人内容。
- 每个梗必须写清：含义、适用场景、语气、禁用场景。
- 不一次性塞给模型；系统只放少量精选，具体弹幕命中时才注入对应条目。
- 不要求模型解释梗；观众问起时再用自己的话解释。

## 精选条目

| 梗 | 核心理解 | 适合 |
| --- | --- | --- |
| 我要验牌 | 玩梗式要求对方亮证据/底牌；配套“牌没有问题” | 互相拆台、明显吹牛 |
| 萝卜纸巾猫 | 小猫蒙题等“真棒”，表达试探、被夸、治愈 | 纠结选择、做对小事 |
| 如何呢又能怎 | 接受无奈后的松弛自嘲 | 加班、排队、小失败 |
| 我去，不早说 | 吐槽关键信息说太晚 | 熟人分享离谱经验 |
| 爱你老己 | 把自己叫“老己”，自我照顾 | 下播、观众说累 |
| 班味 | 上班后的疲惫、机械感 | 周一、开会、打工自嘲 |
| 情绪价值 | 被理解、被安慰的情绪收益 | 安慰、夸内容 |
| 活人感 / 含人量 | 真实、有瑕疵、不像模板生成 | 夸真实分享、吐槽 AI 味 |
| 抽象力 | 荒诞、解构式幽默 | 离谱弹幕、无厘头二创 |
| 边界感 | 保持舒适距离、不越界 | 被问隐私、温和拒绝 |
| 那咋了 | 满不在乎的反问；可松弛也可嘴硬 | 熟人拆台、小事翻篇 |
| 尊嘟假嘟 | “真的假的”的可爱谐音 | 轻松惊讶 |
| 偷感 / 硬控 / 破防 | 自嘲悄悄努力 / 被吸引 / 防线被击穿 | 日常互动 |
| 显眼包 / 搭子 / 电子榨菜 | 亲昵调侃、轻量陪伴、下饭陪伴 | 直播陪伴感 |
| 红温 / 已老实求放过 | 上头急眼 / 玩梗投降 | 被弹幕逗到破功 |
| 松弛感 / 水灵灵地 | 不紧绷 / 理直气壮地做某事 | 心态、反差萌 |
| city不city | 够不够都市/洋气的反差问法 | 城市、旅行、穿搭 |

完整卡牌见 `memes.py`；运行时只会注入命中文本的少量条目，避免每条回复都硬塞梗。
