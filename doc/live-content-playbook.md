# 小鲸直播间内容调研与栏目方案

## 1. 当前问题

现有直播内容主要由：

```text
欢迎进场
回复弹幕
点歌 / 切歌
偶尔时间/身份问答
```

组成。它的问题是：

- 没有固定栏目，观众不知道下一分钟会发生什么
- 单条回复很短，缺少可连续听的内容
- 互动只停留在“问一句答一句”，没有参与感
- 主播没有“正在做一件事”的现场感
- 观众没有回来的理由

## 2. 内容支柱

建议把直播内容分成 5 个支柱，不要把所有东西混成随机聊天。

### A. 长篇故事 / 深夜电台

适合时段：

```text
20:30-21:00
22:30-23:30
```

形式：

```text
讲个故事
继续
别讲了
换一个故事
```

可做的题材：

- 深海/蓝鲸娘的奇幻故事
- 深夜电台来信
- 轻悬疑连续故事
- 童话但不幼稚的成人寓言
- 赛博城市里的小妖怪
- 观众投票决定下一段走向

当前已实现的命令：

```text
讲个故事
讲一个深夜电台的故事
继续 / 后来呢
别讲了 / 打断
```

礼物和普通弹幕可以打断故事，先处理礼物感谢，再决定是否继续。

### B. 互动游戏

建议先做低成本、弹幕参与感强的：

1. **猜歌**：播放 3 秒前奏，观众打字猜歌名
2. **猜台词**：念一句影视/动漫台词，猜出处
3. **二选一**：A/B 投票决定小鲸下一步
4. **故事接龙**：观众提供一个人物/地点，小鲸接一段
5. **反向问答**：小鲸问观众问题，观众答，抽一个回应
6. **今日挑战**：例如“全程不嘴硬”“用三个词讲完一个故事”

### C. 情绪陪伴

- 深夜树洞：读观众投稿（需要审核/脱敏）
- 夸夸/吐槽：观众说一个烦恼，小鲸用嘴硬心软的方式回应
- 晚安电台：低音量、慢节奏、固定收尾
- 点歌 + 歌曲背后的故事

### D. 人格整活

- “小鲸今天的人设实验”：例如只许用 10 个字回答
- “AI 翻车复盘”：读自己之前的离谱回复
- “嘴硬挑战”：观众夸，必须嘴硬三次
- “小鲸不知道”：专门回答不确定的问题，训练承认不知道

### E. 轻知识 / 热点

- 今日冷知识
- 科技/游戏/动画话题
- 观众提问箱
- 热点事件只做事实梳理，不站队、不造谣

## 3. 推荐节目单

### 90 分钟基础排期

```text
00:00-00:05  开场 + 今日话题
00:05-00:15  弹幕互动 / 点歌
00:15-00:35  长故事第一段（悬念收尾）
00:35-00:45  礼物感谢 + 观众选择继续/换故事
00:45-01:00  猜歌/二选一
01:00-01:15  观众提问/夸夸吐槽
01:15-01:25  晚安电台收尾
01:25-01:30  关注引导 + 明日预告
```

### 每 10 分钟必须发生的互动

```text
一次提问
一次观众名字回应
一次内容节点切换
一次“继续/换一个”选择
```

## 4. 优先级

### P0：现在就能做

- [x] 长故事模式
- [x] 故事中途停止
- [x] 礼物/普通弹幕抢占故事
- [ ] 今日话题固定开场
- [ ] 故事结束后的“继续/换一个”选择
- [ ] 读评论/观众投稿（先审核）

### P1：下一阶段

- [ ] 猜歌模式
- [ ] 二选一投票
- [ ] 故事接龙
- [ ] 固定节目单和倒计时
- [ ] 观众点歌与故事模式互斥/恢复策略

### P2：需要更多制作

- [ ] 多角色配音（旁白/角色不同音色）
- [ ] ASMR/晚安电台音效
- [ ] 观众连线/嘉宾
- [ ] 多主播联动
- [ ] 画面场景切换

## 5. 技术映射

当前代码：

```text
src/open_llm_vtuber/live/story.py
  - 故事生成
  - 故事分段
  - 命令检测
src/open_llm_vtuber/agent/agents/live_streamer_agent.py
  - 故事模式生成/中断
src/open_llm_vtuber/live/runtime.py
  - 礼物/弹幕抢占故事
  - 故事 TTS 中断
```

建议下一层抽象：

```text
ContentDirector
  - 当前栏目：chat / story / game / radio
  - 栏目剩余时间
  - 下一栏目
  - 观众投票结果
  - 礼物优先级
```

不要让“故事模式”继续散落在 agent 和 runtime 里；下一步应把栏目状态提升为独立状态机。

## 6. 指标

每场记录：

```text
平均停留时长
每分钟弹幕数
关注转化
回访观众数
故事段完播率
故事中断率
礼物感谢响应时间
```

不要用“诱导礼物”换指标；礼物感谢只做自然回应，不做金额/榜单比较。

## 7. 风险与边界

- 故事是虚构内容，不冒充真实新闻/真实人物
- 观众投稿必须审核、脱敏，不读隐私信息
- 不主动谈政治、色情、仇恨、违法、医疗投资建议
- 点歌与故事模式要有明确优先级，避免同时播放
- 多角色配音上线前，先确认 TTS 音色和版权
